# Paradise Nursery — Online Plant Shop

Paradise Nursery is a React and Redux Toolkit shopping application for indoor plants.

## Features
- Landing page with the Paradise Nursery company name, a background image, and Get Started navigation
- About Us company description
- Six or more plants grouped into three categories, with photographs, prices, and Add to Cart buttons
- Add to cart once per product; button becomes disabled once added
- Redux cart state with `addItem`, `removeItem`, and `updateQuantity` reducers
- Cart quantity badge, item subtotals, total item count, and total cost
- Cart controls to increase/decrease quantities, delete items, continue shopping, and checkout

## Run
```bash
npm install
npm run dev
```

Open the local URL printed by Vite. All prices are illustrative USD amounts.
